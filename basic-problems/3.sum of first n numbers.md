1. Using a for loop ⭐
n = int(input("Enter n: "))

total = 0

for i in range(1, n + 1):
    total = total + i

print("Sum =", total)

2. Using the mathematical formula 

The sum of the first n natural numbers is:

$$ \frac{n(n+1)}{2} $$

So:

n = int(input("Enter n: "))

total = n * (n + 1) // 2

print("Sum =", total)
