Write a program to print the following pattern
1
1 2 1
1 2 3 2 1
1 2 3 4 3 2 1
1 2 3 4 5 4 3 2 1

i =1 

while i <=5:
      j =1 
      while j <=i:
          print(j, end ="")
          j+=1

      j =i -1
      while j>=1:
          print(j, end ="")
          j-=1
      
      print()
      i+=1

How it works

For each row, we have two parts.

For example, row 4:

1 2 3 4

First loop prints:

j = 1
while j <= i:
    print(j, end=" ")

Then the second loop prints the numbers backwards:

3 2 1

So together:

1 2 3 4 3 2 1
Remember this pattern 🧠

Increasing part:

j = 1
while j <= i:
    print(j, end=" ")
    j += 1

Decreasing part:

j = i - 1
while j >= 1:
    print(j, end=" ")
    j -= 1

The reason we start the second loop with:

j = i - 1

is because we don't want to repeat the highest number.

For row 5:

Increasing → 1 2 3 4 5
Decreasing → 4 3 2 1

Final:

1 2 3 4 5 4 3 2 1
