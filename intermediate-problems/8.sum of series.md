Write a program to calculate the sum of the following series till the nth term
1/1! + 2/2! + 3/3! + 4/4! +…….+ n/n!
n will be provided by the user


Using math module -

import math

n = int(input("Enter n: "))

total = 0

for i in range(1, n + 1):
    total += i / math.factorial(i)

print("Sum =", total)

Using factorial function -
def factorial(n):
    fact = 1

    while n > 0:
        fact = fact * n
        n -= 1

    return fact


n = int(input("Enter n: "))

i = 1
total = 0

while i <= n:
    total = total + i / factorial(i)
    i += 1

print("Sum =", total)
