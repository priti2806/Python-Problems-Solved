Find the LCM of two numbers -

num1 = int(input("Enter first number: "))
num2 = int(input("Enter second number: "))

a = num1
b = num2

while b != 0:
    a, b = b, a % b

hcf = a

lcm = (num1 * num2) // hcf

print("LCM =", lcm)

Explanation-  Finding LCM

We use this formula:

LCM × HCF = num1 × num2

Therefore:

LCM = (num1 × num2) / HCF

In Python:

lcm = (num1 * num2) // hcf

For 12 and 18:

LCM = (12 × 18) / 6
    = 216 / 6
    = 36

So:

LCM = 36
